## “Tell us about the project's reach and impact”

I maintain BalNLP, an early-stage Arabic-script Balochi NLP toolkit. Its source brings
POS tagging, named entity recognition, morphology, and dependency parsing together
through a Python library, FastAPI service, and RTL web workspace with JSON and CoNLL-U
exports. It connects related Balochi model work through a common interface so that
researchers, students, and developers can experiment with fewer integration steps.

My aim is useful language infrastructure for Balochi, with human linguistic review
and reproducible evaluation. I am not claiming established adoption: the repository
had 0 stars and 0 forks when checked on 21 September 2026, and I do not have verified
download, dependent-package, or external-user figures. Source licensing is still being
finalized, and the recorded free API host lacks sufficient memory for public model
inference. I am seeking discretionary consideration based on the project's scope and
maintenance needs, not claiming that it meets the program's numerical thresholds.

## “How will you use the subscription for your project?”

I would use Claude to assist with reviewing pull requests, debugging model adapters,
writing and reviewing tests, improving API and packaging documentation, triaging issues,
and checking security-sensitive code paths. I also want to improve reproducible setup,
error messages, RTL accessibility, and multilingual contributor guidance. I would review
all generated changes and verify model behavior against documented sources. Claude
would support maintenance; it would not replace Balochi speakers' linguistic validation,
held-out evaluation, or human decisions about licensing and research claims.
