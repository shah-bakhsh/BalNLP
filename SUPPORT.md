# Getting help

Start with the [README](README.md), [API contract](docs/API.md), and
[deployment guide](docs/DEPLOYMENT.md). Use repository issues for reproducible bugs,
feature proposals, documentation questions, or linguistic/model feedback. Include
commit/version, Python or Node version, operating system, settings with secrets removed,
and a small non-sensitive example you have permission to share.

`RESOURCE_LIMITED` on a 512 MB host is expected with the published checkpoints.
A successful health check does not show that models can run. See [model details](docs/MODELS.md).

For vulnerabilities use [SECURITY.md](SECURITY.md), not a public issue. For conduct
concerns use [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Project questions can also be
sent to Shah Bakhsh at shahbakhshtech@gmail.com. This is a research project without a
support SLA; please allow time for volunteer maintenance.
